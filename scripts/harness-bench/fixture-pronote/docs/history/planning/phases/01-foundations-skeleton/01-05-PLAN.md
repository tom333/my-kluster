```yaml
# Hooks adapted from HA Core master .pre-commit-config.yaml.
# Locally runs the same checks as CI lint.yml so contributors fail fast.
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.15.1
    hooks:
      - id: ruff-format
        files: ^((custom_components|tests)/.+)?[^/]+\.(py|pyi)$
      - id: ruff-check
        args: [--fix]
        files: ^((custom_components|tests)/.+)?[^/]+\.(py|pyi)$
  - repo: https://github.com/codespell-project/codespell
    rev: v2.4.1
    hooks:
      - id: codespell
        args:
          - --ignore-words-list=hass
          - --quiet-level=2
        exclude_types: [csv, json, html]
        exclude: ^tests/fixtures/
  - repo: local
    hooks:
      - id: pyright
        name: pyright
        entry: npx pyright
        language: node
        types: [python]
        pass_filenames: false
```

Anti-pattern guards:
- Ruff rev (`v0.15.1`) AND codespell rev (`v2.4.1`) MUST be byte-identical to the corresponding `requirements_test.txt` pins (Plan 01) — version drift means CI and local-hook outcomes diverge silently.
- The local pyright hook uses `language: node` (not `language: system`) so it runs against the project's npm-pinned pyright (Plan 01 `package.json` — `pyright==1.1.409`), NOT a globally-installed pyright. `pass_filenames: false` because pyright reads `pyproject.toml` `[tool.pyright] include` for its targets — passing filenames would override that.
- `exclude: ^tests/fixtures/` is a forward-looking guard — Phase 1 has no fixtures dir but Phase 2+ will, and codespell would otherwise flag intentional misspellings in test fixtures.
- `files: ^((custom_components|tests)/.+)?[^/]+\.(py|pyi)$` for ruff is a pragma — it limits ruff to .py/.pyi files in `custom_components/` and `tests/`, but also catches root-level Python files (e.g., a future `scripts/` script). Match HA Core master verbatim.
